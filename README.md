# Vision Telecom

Homepage estática responsiva e otimizada para a Vision Telecom.

## Desenvolvimento local

Abra o `index.html` diretamente no navegador ou use a extensão Live Server da sua IDE.

## Publicação

O projeto não precisa de build nem de dependências. Envie a raiz desta pasta para qualquer hospedagem estática.

- **Netlify:** importe a pasta/repositório; o `netlify.toml` já define a publicação e o cache.
- **Vercel:** importe o repositório com o preset **Other**; não informe comando de build e mantenha `.` como diretório de saída.
- **GitHub Pages:** publique a raiz do repositório; o arquivo `.nojekyll` já está incluído.

Depois de conectar um domínio próprio, cadastre-o no painel da hospedagem e ative o HTTPS automático.

## Arquivos

- `index.html`: estrutura e conteúdo da página.
- `style.css`: identidade visual e responsividade.
- `script.js`: menu mobile, animações e ano automático.
- `img/`: favicon, imagens WebP usadas pelo site e originais arquivados em `img/originais/` (excluídos do deploy).
- `netlify.toml` e `vercel.json`: cache e cabeçalhos de segurança para deploy.
